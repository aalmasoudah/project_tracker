Insight ProjectsNew: governed recovery agent
Phase 17

The agent plans, proposes, waits, and verifies.

01PlanValidate the predefined goal, scope, step limit, time limit, and token budget.
02ObserveDynamically select safe project reads; each result changes the next choice.
03ProposeCreate cited before-and-proposed values without changing business data.
04ApprovePause for a human reason, then recheck permission, expiry, and stale state.
05VerifyExecute once through domain services and cite the actual post-action state.

Reviewed memory only

No shell, SQL, filesystem, web, arbitrary HTTP, code, credentials, files, trainees, attendance, or raw audit tools.

Insight ProjectsArchitecture and security
Built for a controlled pilot

A maintainable monolith with explicit trust boundaries.

Application

Django 5.2 LTS, Python 3.13, server templates, Bootstrap 5, and HTMX.

Data

PostgreSQL transactions, constraints, indexes, protected records, and scoped selectors.

Background

Celery and Redis for briefings, agents, notifications, retries, and maintenance.

Deployment

Docker, Gunicorn, private S3-compatible storage, secret-managed configuration, and health checks.

Authorization

Authenticated sessions, CSRF, active-account checks, role permissions, and object-level scope at views, tools, approvals, execution, and exports.

Arabic and privacy

Preserved Unicode, reviewed search normalization, RTL/LTR, mixed-content isolation, private files, bounded audit metadata, and no production DEBUG.

Portable architecture; hosting region and SSO remain university decisions10 / 13
